# 🌕 Happy Anniversary — เทศกาลลอยกระทงของเรา

เว็บแอป Streamlit ธีมลอยกระทง/พระจันทร์เต็มดวง ส่งลิงก์ให้แฟนเปิดเล่นได้ตั้งแต่ต้นจนจบ

**โฟลว์:** เริ่ม → แล่นเรือความทรงจำ (รูปของเราลอยขึ้นจากเรือ แล้ว "เขียน" happy anniversary ตูด)
→ ตกแต่งกระทง + เลือกคำอธิษฐาน → ปล่อยโคม (คำอธิษฐานของทั้งสองคนขึ้นบนโคม) + ลอยกระทง → จดหมาย

## 1) ใส่ของของคุณ

| อะไร | ใส่ที่ไหน |
|---|---|
| รูปความทรงจำ ~20 รูป | `assets/photos/` — เรียงตามชื่อไฟล์ (`01.jpg`, `02.jpg` …) ✅ ใส่ครบ 20 รูปแล้ว |
| รูปหน้าของ "คุณ" | `assets/faces/me.jpg` ✅ ใส่แล้ว |
| รูปหน้าของ "แฟน" | `assets/faces/partner.jpg` ✅ ใส่แล้ว |
| ชื่อ / **คำอธิษฐานของคุณ (`ME_WISH` — ต้องพิมพ์เอง)** / จดหมาย / กระทงของคุณ | `config.py` |
| คำบรรยายใต้รูป (ไม่บังคับ) | `assets/photos/captions.json` → `{"01.jpg": "วันแรกที่เจอกัน"}` |

- รูปหน้าจะถูกครอปเป็นวงกลมกลางรูป ถ้าหน้าไม่อยู่กลาง ปรับ `FACE_FOCUS` ใน `config.py`
- รูปจาก iPhone ที่เป็น `.HEIC` ต้องมี `pillow-heif` (อยู่ใน requirements.txt แล้ว) หรือแปลงเป็น .jpg ก่อน
- ถ้ายังไม่ใส่รูป แอปจะโชว์รูปตัวอย่างให้ดูก่อน

## 2) รันดูในเครื่อง (VS Code)

```bash
pip install -r requirements.txt
streamlit run app.py
```

เปิด `http://localhost:8501/?edit=1` = **โหมดคนทำ** → มีเมนูกระโดดข้ามหน้า, ปุ่มไม่ล็อก,
และตกแต่งกระทงแล้วก๊อปค่าไปวางเป็น `ME_KRATHONG` ของคุณได้
(ลิงก์ที่ส่งให้แฟนไม่ต้องมี `?edit=1`)

## 3) ส่งลิงก์ให้แฟน

**แบบถาวร (แนะนำ):** [Streamlit Community Cloud](https://share.streamlit.io) — ฟรี
1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub (เลือก **Private** ได้ เพราะมีรูปส่วนตัว)
2. ล็อกอิน share.streamlit.io → New app → เลือก repo, branch, ไฟล์ `app.py` → Deploy
3. ได้ลิงก์ `https://ชื่อที่ตั้ง.streamlit.app` ส่งให้แฟนได้เลย (เปิดบนมือถือได้)

**แบบชั่วคราว:** รัน `streamlit run app.py` แล้วเปิดอุโมงค์ เช่น `cloudflared tunnel --url http://localhost:8501`
(ลิงก์ใช้ได้ตราบที่เครื่องคุณยังเปิดอยู่)

## ปรับแต่งเพิ่ม

- ความเร็วเรือ: `SECONDS_PER_PHOTO` — ตัวเลขน้อย = รูปเปลี่ยนไวขึ้น
- ปุ่ม "ไปต่อ" ในหน้าแล่นเรือล็อกไว้จนเรือแล่นจบ (ให้แฟนดูครบทุกรูป) ปิดได้ที่ `LOCK_NEXT_UNTIL_SAIL_ENDS = False`
- ตัวเลือกกระทง (ฐาน/ดอกไม้/เทียน/สติกเกอร์) แก้เพิ่มได้ใน `scenes.py` ส่วน "ตัวเลือกกระทง"
- ฟอนต์ใช้ Google Fonts (Mali / Itim) ต้องมีอินเทอร์เน็ตตอนเปิด ถ้าไม่มีจะใช้ฟอนต์ไทยของเครื่องแทน

## โครงไฟล์

```
app.py        โฟลว์ 5 หน้า + ธีม
config.py     ชื่อ ข้อความ คำอธิษฐาน จดหมาย  ← แก้ไฟล์นี้เป็นหลัก
scenes.py     ฉากภาพเคลื่อนไหว (เรือ/ตัวการ์ตูน/โพลารอยด์/กระทง/โคม) เป็น HTML+SVG
assets.py     ย่อรูป ครอปใบหน้า
assets/       photos/ faces/
```
